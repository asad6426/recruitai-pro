       tween different pages without reloading the application.

       tainability.

    · Forms and Validation: I implemented Template-driven Forms with input validation to

4.3 Developing a Library Management System

As the final development project during my internship, I developed a Library Management
System using Angular. The purpose of this project was to build a complete web application
that simulates the workflow of a real library management system. The application supports
two different user roles: User and Administrator. Users can browse available books, read book
details, and submit borrowing requests. The administrator reviews the requests and approves or
rejects them. Once approved, the user can borrow the selected book. The system automatically
tracks the borrowing period, and if the due date is exceeded, a fine is generated and a notification
is sent to the user.
Key Activities:

    · Designed separate User and Admin modules.
    · Developed book browsing and search functionality.
    · Implemented borrow request management.
    · Built admin approval and rejection system.
    · Added due date calculation.
    · Implemented automatic fine generation.
    · Sent overdue notification messages to users.
    · Created responsive and user-friendly interfaces.
Learning Outcomes:
    · Role-Based Access Control
    · CRUD Operations
    · Business Logic Implementation
    · Notification Workflow
    · Fine Calculation System
    · Real-world Application Development
